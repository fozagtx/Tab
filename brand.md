# Brand — Tab

Status: active

## Mood
Thermal receipt — ink on stock, perforated stubs, one gold CTA.

## Palette
| Role | Hex |
|---|---|
| Paper | `#FBFAF7` |
| Ink | `#1F2348` |
| Edge | `#EFEAE0` |
| Muted | `#6B708C` |
| Gold CTA | `#E9B213` → `#FC8702` |
| Paid | `#21BCA5` |
| Alert | `#D94432` |

## Typography (Nimiq official)
- **Sans:** Mulish (Google’s current name for Nimiq’s Muli)
- **Mono:** Fira Mono (addresses, amounts, codes, memos)
- Scale: 11 meta · 16 body · 28 title · 34 display · 52 money
- Display tracking ~-3.5%; body leading 1.5; measure ~36ch on helpers

## Layout
Single column, max 390px. Thumb CTA sticky. No cards in hero. Dashed perforation between shares.
